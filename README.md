# Фінансовий радник

Автономний застосунок: живі ціни крипти, фондового ринку й золота (Crypto.com, резерв Binance/OKX),
індекс страху й жадібності, свічкові графіки 5 хв – 6 міс., авто-сигнал за правилами
та щоденний бриф (`data/brief.json`, оновлює Claude щоранку).

- Відкрити: https://dehluloo.github.io/finadvisor/
- Дані оновлюються кожні 4 години і кнопкою «Оновити»; портфель зберігається лише на пристрої.
- `tools/build_data.py` — збирає `data/brief.json` і `data/brief.js` з даних брифу.

Це інформація, а не індивідуальна фінансова порада.
