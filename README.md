# FinRAD — Фінансовий радник

Автономний застосунок для iPhone і Mac: живі ціни крипти, фондового ринку й золота (Crypto.com, резерв Binance/OKX),
новини наживо з перекладом, індекс страху й жадібності, свічкові графіки 5 хв – 6 міс., карта ліквідацій,
ранковий бриф і **сповіщення навіть коли програма закрита**.

- Відкрити: https://dehluloo.github.io/finadvisor/ (на iPhone: Safari → Поділитися → «На початковий екран»).
- Це інформація, а не індивідуальна фінансова порада.

## Як це працює (4.0)

| Частина | Де | Що робить |
|---|---|---|
| Програма | GitHub Pages (`index.html`, `app.js`, `sw.js`) | Показує все, ціни щосекунди напряму з бірж, портфель і налаштування — лише на пристрої |
| Сервер | Cloudflare Worker `finrad.paulmeizy.workers.dev` (`worker/`) | **Щохвилини**: новини з 9 сайтів і 5 Telegram-каналів, переклад, календар, ф'ючерси; push-сповіщення; Telegram-бот; автобриф щопівгодини |
| База | Cloudflare D1 `finrad` | Новини за 48 год, підписки на сповіщення, стан бота, журнал помилок |

- **Push-сповіщення** (Web Push, стандарт VAPID): важливі новини, рухи цін ±5%, нагадування за 45 хв до подій США, ваші цінові сповіщення.
  Увімкнути: Налаштування → «Сповіщення на цьому пристрої». На iPhone — лише з іконки на головному екрані (iOS 16.4+).
- **Telegram-бот** (необов'язково): секрет `TELEGRAM_BOT_TOKEN` у GitHub → Actions → «Cloudflare Worker» → Run workflow → у боті Start.
- **Бриф**: автоматичний за правилами (щопівгодини). Кнопка «Глибокий аналіз від Claude» відкриває Claude з готовим запитом і свіжими даними;
  якщо Claude оновить `data/brief.json` з `"source": "claude"`, програма покаже цей аналіз протягом доби.
- `worker/` розгортається автоматично при зміні (workflow `worker.yml`). Старий збирач на GitHub Actions (`live.yml`) — лише ручний резерв.

## Адреси Worker
`/live` — новини й дані · `/brief?lang=uk|en` — автобриф · `/config` — ключ push і стан бота · `/push/subscribe|prefs|state|test|unsubscribe` ·
`/tg/…` — webhook бота · `/health` — стан збирача · `/log`, `/logs` — анонімні звіти про помилки.
